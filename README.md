# Hospital Admission Forecasting (STP)

Patient admission forecasting work from my Summer Training Program (STP) internship at Dynamed Healthcare Solutions, Kochi.

The goal was to forecast patient admissions across multiple hospital locations so that medical records and operations teams can plan ahead. Forecasting methods compared include SARIMA, ETS, Prophet and XGBoost.

## Status

This repository currently holds only the license. The internal analysis ran on confidential hospital data that cannot be published. Only synthetic datasets (labelled Facility 1 to 6) are cleared for public use.

The public, runnable version of this work lives here:

- Code and demo: [hospital-admission-forecasting](https://github.com/DrEnosh/hospital-admission-forecasting)
